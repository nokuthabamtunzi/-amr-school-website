# AMR Primary School with ECD

This repository contains a premium school website concept built with Next.js 14, TypeScript, Tailwind CSS and Supabase.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Key folders
- `/app` – pages and layout
- `/components` – reusable UI
- `/config` – editable settings
- `/lib` – site data and Supabase helper
- `/public/images` – placeholder school and logo assets
- `/supabase.sql` – database schema

## Deployment
- Use Vercel
- Add environment variables from `.env.example`
- Upload your real AMR photos and logos later
